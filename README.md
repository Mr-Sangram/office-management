# Advance System Company Management - Enterprise ERP

A complete, production-grade 24/7 Cloud ERP & Interior Project Management System.
Features include automated Google Drive / Google Sheets real-time synchronization, granular multi-role permissions (Owner, Manager, Site Supervisor, Accountant, Client), client view protection, petty cash ledger, inventory, attendance, and payroll.

## 🚀 One-Click Vercel Deployment

1. **Push or Upload this entire repository** to your GitHub account (make sure all folder structures including `src/` are preserved).
2. Go to [Vercel](https://vercel.com) and click **"Add New..." -> "Project"**.
3. Import your GitHub repository.
4. Framework Preset: **Vite** (auto-detected).
5. Build Command: `npm run build`
6. Output Directory: `dist`
7. Click **Deploy**.

Your app is now live 24/7 on Vercel with automatic HTTPS and global CDN!

## 🔄 Google Drive & Sheets Sync
- Go to the **Google Drive & Sheets Sync (গুগল ড্রাইভ ও শিট ব্যাকআপ)** panel inside the app.
- Click **"Apps Script কোড (Code.gs)"** to copy the script into your Google Sheet's Apps Script editor.
- Deploy as Web App with **"Who has access: Anyone"**.
- Paste the Web App URL into the app's settings.
- All ERP entries will automatically sync to your Google Drive and Google Sheets 24/7!
